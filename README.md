SpecBridge 전문어 테스트용
프론트엔드에서 로그인 폼을 구현한 다음 백엔드 API와 연동하면 됩니다. 로그인에 성공하면 서버에서 받은 토큰을 저장하고 메인 페이지로 라우팅해주세요.

현재 와이어프레임을 기준으로 프로토타입을 제작하고 있습니다. UI의 일관성을 위해 디자인 시스템을 적용하고, CTA 버튼의 위치를 변경해서 사용자 플로우를 개선할 필요가 있습니다.

사용자 비밀번호는 평문으로 저장하면 안 되고 해시 알고리즘을 적용해야 합니다. 인증이 완료된 사용자는 JWT를 발급하고 API 요청마다 토큰의 유효성을 검증해주세요.

초음파 센서로 측정한 거리값을 MCU에서 처리하고 임계값보다 작아지면 서보모터를 동작시키겠습니다. 센서 데이터는 ESP8266을 통해 서버로 전송하고 관리자 대시보드에서 실시간으로 확인하도록 구현할 예정입니다.

# SpecBridge 회의 요약 테스트 대화

김기획: 이번 주 안으로 로그인 기능이랑 회원가입 기능의 MVP를 완성했으면 좋겠습니다. 우선 핵심 기능부터 개발하고 부가 기능은 다음 스프린트로 넘기죠.

이개발: 로그인 API는 오늘부터 작업하겠습니다. JWT 방식으로 인증을 구현하고 금요일까지 백엔드 작업을 완료할 수 있을 것 같습니다.

박프론트: 로그인 화면 UI는 이미 거의 완성됐습니다. 백엔드 API가 나오면 바로 연동할 수 있는데, 로그인 실패 시 에러 메시지를 어떻게 보여줄지는 아직 정해지지 않았습니다.

최디자인: 에러 메시지는 입력창 아래에 표시하는 방식으로 디자인하겠습니다. 회원가입 페이지 프로토타입도 내일까지 전달하겠습니다.

김기획: 좋습니다. 회원가입에는 이름, 이메일, 비밀번호만 우선 받는 것으로 하겠습니다. 소셜 로그인은 MVP에서는 제외하죠.

이개발: 회원가입 API도 로그인 API와 같이 만들겠습니다. 비밀번호는 그대로 DB에 저장하지 않고 해시 처리해서 저장하겠습니다.

박프론트: 그러면 API 명세가 나오면 로그인과 회원가입 화면을 연결하겠습니다. API 응답은 JSON 형태로 받는 게 맞나요?

이개발: 네. 성공 여부, 메시지, 사용자 정보 정도를 JSON으로 전달하겠습니다. API 명세서는 내일까지 공유하겠습니다.

김기획: 배포 일정도 정해야 합니다. 다음 주 월요일에 내부 테스트를 하고 문제가 없으면 수요일에 테스트 서버에 배포하는 것으로 하죠.

박프론트: 모바일 화면 반응형 작업은 이번 일정에 포함되나요?

김기획: 기본적인 반응형까지만 이번 스프린트에서 진행하고 세부적인 모바일 UX 개선은 다음에 진행하겠습니다.

최디자인: 그러면 저는 내일까지 회원가입 프로토타입과 에러 메시지 디자인을 전달하겠습니다.

이개발: 저는 내일까지 API 명세서를 공유하고 금요일까지 로그인과 회원가입 API를 완료하겠습니다.

박프론트: API가 완성되면 금요일 오후부터 연동 작업을 시작하겠습니다.

김기획: 정리하면 다음 주 월요일 내부 테스트, 수요일 테스트 서버 배포를 목표로 하겠습니다. 소셜 로그인과 세부 모바일 UX 개선은 이번 MVP에서는 제외하는 것으로 결정하겠습니다.

# 캠퍼스메이트 — 대학생 일정·과제 통합 관리 서비스 기획안

## 1. 프로젝트 개요

### 서비스명

캠퍼스메이트(CampusMate)

### 한 줄 소개

대학생의 수업 일정, 과제, 시험 일정을 한 곳에서 관리하고 AI가 우선순위를 추천해주는 일정 관리 서비스

### 기획 배경

대학생들은 여러 강의의 과제, 시험, 팀 프로젝트 일정을 동시에 관리해야 한다.

하지만 일정이 학교 LMS, 카카오톡, 교수 공지, 개인 메모 등 여러 곳에 흩어져 있어 제출 기한을 놓치거나 중요한 일정을 잊는 경우가 있다.

특히 시험 기간이나 팀 프로젝트가 겹칠 경우 어떤 일을 먼저 해야 하는지 판단하기 어렵다는 문제가 있다.

캠퍼스메이트는 이러한 문제를 해결하기 위해 수업과 과제 일정을 한 곳에서 관리하고 AI가 해야 할 일의 우선순위를 정리해주는 서비스를 제공한다.

---

## 2. 주요 사용자

주요 사용자는 대학생이다.

특히 다음과 같은 학생을 대상으로 한다.

* 여러 과제를 동시에 진행하는 학생
* 시험과 과제 일정을 자주 놓치는 학생
* 팀 프로젝트를 많이 진행하는 학생
* 일정 관리가 어려운 학생

---

## 3. 핵심 기능

### 1) 수업 일정 관리

사용자가 자신의 수업을 등록할 수 있다.

등록 정보는 다음과 같다.

* 강의명
* 교수명
* 강의 요일
* 강의 시간
* 강의실

등록된 수업은 주간 시간표 형태로 확인할 수 있다.

---

### 2) 과제 관리

강의별 과제를 등록할 수 있다.

사용자는 다음 정보를 입력한다.

* 과제 이름
* 관련 강의
* 제출 기한
* 과제 설명

과제 제출 기한이 가까워지면 메인 화면에 표시한다.

---

### 3) 시험 일정 관리

중간고사, 기말고사 등의 시험 일정을 등록할 수 있다.

시험 날짜가 가까워지면 사용자에게 알려준다.

---

### 4) AI 우선순위 추천

등록된 과제와 시험 일정을 AI가 분석한다.

AI는 제출일까지 남은 시간과 사용자가 설정한 중요도를 기준으로 해야 할 일을 추천한다.

예를 들어 다음과 같이 표시한다.

1순위: 데이터베이스 과제 제출
2순위: Java 시험 공부
3순위: 팀 프로젝트 발표자료 제작

사용자가 오늘 해야 할 일을 빠르게 확인할 수 있도록 하는 것이 목적이다.

---

### 5) 오늘의 할 일

메인 화면에서 오늘 진행해야 할 일정을 보여준다.

예시:

* 데이터베이스 과제 제출
* Java 시험 공부
* 팀 프로젝트 회의
* 알고리즘 강의

완료한 일정은 체크할 수 있다.

---

## 4. 주요 화면

### 메인 화면

사용자가 로그인하면 가장 먼저 확인하는 화면이다.

다음 정보를 제공한다.

* 오늘의 수업
* 오늘의 할 일
* 제출 임박 과제
* 다가오는 시험
* AI 추천 우선순위

---

### 시간표 화면

주간 시간표를 확인할 수 있다.

요일별로 등록된 강의를 표시한다.

---

### 과제 화면

현재 등록된 과제를 확인할 수 있다.

과제는 제출일 순서로 정렬한다.

완료한 과제는 별도로 표시한다.

---

### 일정 추가 화면

사용자가 새로운 과제나 시험을 등록할 수 있다.

---

## 5. 서비스 사용 흐름

사용자가 서비스에 접속한다.

↓

회원가입 또는 로그인한다.

↓

수업 정보를 등록한다.

↓

과제와 시험 일정을 등록한다.

↓

AI가 등록된 일정의 우선순위를 분석한다.

↓

사용자는 메인 화면에서 오늘 해야 할 일을 확인한다.

↓

완료한 일정은 완료 처리한다.

---

## 6. 개발 기술

프론트엔드는 React를 사용한다.

백엔드는 Node.js를 사용할 예정이다.

데이터베이스는 Firebase를 고려하고 있다.

AI 기능은 외부 AI API를 활용할 예정이다.

배포는 무료 또는 저비용 서비스를 활용할 계획이다.

---

## 7. MVP 기능

초기 버전에서는 다음 기능을 우선 개발한다.

* 회원가입 및 로그인
* 수업 등록
* 과제 등록
* 시험 일정 등록
* 오늘의 할 일
* AI 우선순위 추천

다음 기능은 이후 추가할 예정이다.

* 친구와 일정 공유
* 팀 프로젝트 일정 공유
* 학교 LMS 연동
* 자동 과제 등록
* 푸시 알림
* 모바일 앱

---

## 8. 기대 효과

사용자는 여러 곳에 흩어진 수업과 과제 정보를 하나의 서비스에서 관리할 수 있다.

또한 AI가 중요한 일정을 우선적으로 추천하기 때문에 사용자가 직접 모든 일정의 우선순위를 판단해야 하는 부담을 줄일 수 있다.

이를 통해 과제 제출 누락이나 시험 일정 확인 실수를 줄이고 효율적인 대학생활을 지원할 수 있다.

---

## 9. 향후 확장

향후 학교 LMS와 연동하여 교수자가 등록한 과제나 시험 일정을 자동으로 가져오는 기능을 추가할 수 있다.

또한 팀 프로젝트 기능을 추가하여 팀원들이 하나의 프로젝트 일정을 공유하고 담당 업무를 관리할 수 있도록 확장할 예정이다.
